### 2.1 第一层：找nccl的 so

* 指定了 `VLLM_NCCL_SO_PATH` 环境变量的话，vllm 就回去找我们指定的、
* 否则，看当前是 CUDA/HIP(ROCm) 选对应的通信库。
```py title="find nccl so"
def find_nccl_library() -> str:
    """Return NCCL/RCCL shared library name to load.

    Uses `VLLM_NCCL_SO_PATH` if set; otherwise chooses by torch backend.
    """
    so_file = envs.VLLM_NCCL_SO_PATH
    if so_file:
        logger.info(
            "Found nccl from environment variable VLLM_NCCL_SO_PATH=%s", so_file
        )
    else:
        if torch.version.cuda is not None:
            so_file = "libnccl.so.2"
        elif torch.version.hip is not None:
            so_file = "librccl.so.1"
        else:
            raise ValueError("NCCL only supports CUDA and ROCm backends.")
        logger.debug_once("Found nccl from library %s", so_file)
    return so_file
```

### 2.2 第二层：Python 封装 NCCL C API (`pynccl_wrapper.py`)

在 `PyNcclCommunicator` 类的成员 nccl ，通过 `self.nccl = NCCLLibrary(library_path)` 实例化 NCCLibrary。

在NCCLibrary的实现里面做了两件事情：

a）用 `ctypes.CDLL` 去打开了前面 nccl 的 so 文件
```py title="加载动态库"
def __init__(self, so_file: str | None = None):
    so_file = so_file or find_nccl_library()

    try:
        if so_file not in NCCLLibrary.path_to_dict_mapping:
            lib = ctypes.CDLL(so_file)
            NCCLLibrary.path_to_library_cache[so_file] = lib
        self.lib = NCCLLibrary.path_to_library_cache[so_file]
    except Exception as e:
        logger.error(
            "Failed to load NCCL library from %s. "
            // ... error message ...
        )
        raise e
```

b) 签名表定义了 python->so内 c api 的返回参数 和 传进去什么格式值，`ctypes`会去管理传下去传上来。
```py title="绑定所有导出函数的签名"
if so_file not in NCCLLibrary.path_to_dict_mapping:
```

**发起方**：生成 uniqueI--->ZMQ(socket) 发送给远端---->自己以 `rank=0, world_size=2` 调 `ncclCommInitRank` 建立通信器。

**接收方：** 从 ZMQ 收 uniqueID的 128 字节数据，然后还原成 `ncclUniqueId` 结构体，自己再以 rank=1 去调用`ncclCommInitRank` 建立通信器。
```py title="receiver"
    def listen_for_requests(self):
        while True:
            // ...
            if data["cmd"] == "NEW":
                unique_id = self.nccl.unique_id_from_bytes(bytes(data["unique_id"]))
                with torch.accelerator.device_index(self.device.index):
                    rank = 1
                    with set_p2p_nccl_context(self.nccl_num_channels):
                        comm: ncclComm_t = self.nccl.ncclCommInitRank(
                            2, unique_id, rank
                        )
                    self.comms[remote_address.decode()] = (comm, rank)
```

**3）实际 send/recv 传输**
发送端 (`send_sync`)：

1. 通过 ZMQ 发送元信息（`cmd: "PUT"`, tensor_id, shape, dtype）
2. 等待对方回复确认（对方已分配好接收 buffer）
3. 调用 `self.send(comm, tensor, dst, stream)` 执行 NCCL send

接收端 (`listen_for_requests` 处理 "PUT")：

1. 从 ZMQ 收到元信息
2. 在 GPU 上 `torch.empty(shape, dtype, device)` 分配接收 buffer
3. 通过 ZMQ 回复 "0"（确认 OK）
4. 调用 `self.recv(comm, tensor, src, stream)` 执行 NCCL recv
5. 将收到的 tensor 放入 `recv_store`，通知等待的消费者

**1) prefill 实例的 producer 端 — `save_kv_layer()`**

对每一层 attention 的 KVcache 根据 block_ids 从 **paged kv buffer** 中抽取对应的 **kv tensor**，然后以 `request_id#layer_name` 为 tensor_id，调用引擎的 `send_tensor` 发出去。
```py title="extract_kv_from_layer()"
def extract_kv_from_layer(
    layer: torch.Tensor,
    block_ids: torch.Tensor,
) -> torch.Tensor:
    if layer.ndim == 3 or layer.shape[1] == 2:  # MLA or FlashInfer
        return layer[block_ids, ...]
    if layer.shape[0] == 2:  # FlashAttention
        return layer[:, block_ids, ...]
    return None
```
