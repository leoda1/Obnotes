## vscode远程端口转发
1. 在你的本地电脑上，打开 SSH 配置文件 `~/.ssh/config`
2. 在远程服务器上增加 `RemoteForward 7897 127.0.0.1:7897`
   ```cpp
   Host my-remote-server
    HostName 192.168.x.x
    User root
    # 添加下面这一行
    # 格式: RemoteForward <远程端口> <本地地址>:<本地端口>
    RemoteForward 7897 127.0.0.1:7897
   ```
3. 在remote端 VSCode 设置里搜 http.proxy 并设置为 http://127.0.0.1:7897
