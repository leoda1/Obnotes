2. **怎么看会话列表，会话怎么命名**

- 进入 Claude Code 后，欢迎页会显示 **recent conversations**。官方 quickstart 明确写了启动后会看到 “session information, recent conversations, and latest updates”。
- 更完整地看会话列表，用：
    - `claude --resume`
    - 或在当前会话里用 `/resume`  
        这会打开 **session picker**。官方写明它会显示同一 git 仓库里的交互式会话，还支持筛选和预览。
- 会话命名有 3 种官方方式：
    - 启动时命名：`claude -n auth-refactor`
    - 会话中重命名：`/rename auth-refactor`
    - 在 `/resume` 的 picker 里选中会话后按 `R` 重命名。
- 命名后，后面还能按名字恢复：
    - `claude --resume auth-refactor`
    - 或在会话里 `/resume auth-refactor`。

3. **`/clear` 是不是清空当前所有 memory，但不清空 `CLAUDE.md`**

不是。`/clear` 的官方定义只是 **“清除对话历史”**。

结合 memory 文档，Claude Code 的跨会话记忆分成两套：

- `CLAUDE.md`：你写的持久说明
- auto memory：Claude 自己记的 learnings  
    而且这两者都会在每次对话开始时加载。

所以按官方定义来理解：

- `/clear` 清的是**当前会话的聊天历史**
- **不会删除 `CLAUDE.md`**
- 也**不是“把所有 memory 文件删掉”**  
    这点文档没有逐字写成“/clear 不删除 memory 文件”，但从 `/clear = clear conversation history` 加上 “memory 在每次会话开始加载” 可以明确推出来。

4. **多个会话的话怎么快速跳转**

最快有几种：

- **回到最近一个会话**：`claude --continue`。官方说明这是继续当前目录最近一次会话。
- **打开会话选择器**：`claude --resume`，或在会话里 `/resume`。
- 在 picker 里常用快捷键：
    - `↑ / ↓`：上下选会话
    - `Enter`：进入
    - `P`：预览
    - `R`：重命名
    - `/`：搜索过滤
    - `A`：当前目录 / 全部项目切换
    - `B`：只看当前 git 分支
    - `Esc`：退出。
- **如果你平时给会话起名**，最快方式通常是直接：
    - `claude --resume 会话名`
    - 或 `/resume 会话名`。

你这个场景里，最好记住这 5 个就够了：

claude update  
claude --continue  
claude --resume  
claude -n my-task-name  
/resume
